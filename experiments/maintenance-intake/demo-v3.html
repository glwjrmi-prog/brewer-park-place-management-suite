How it will work

Submitted → Board reviews governing documents and priority → Board approves a determination → Resident sees approved status → HOA work is scheduled, deferred, or completed. The live version will have secure logins, appropriate photos, notifications, and automatic authorized work-order entry. Urgent alerts will go to every active board member, with one member explicitly acknowledging coordination. This preview only simulates alerts.
